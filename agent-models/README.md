# Agent Models

**Status:** reserved scaffold; no agent-model implementation was present in the reviewed baseline.

Document modeled agent capabilities, policies, observation/action boundaries, communication, environment assumptions, interaction rules and the reason each is plausible. Identify which behaviors are measured, stipulated, or merely hypothesized.

Evaluate adverse cases, coordination failures and relevant distribution shifts. The number of agents or the appearance of emergent behavior is not evidence of safety or real-world transfer. Record evaluator independence, limitations and the exact scope supported by each result.
