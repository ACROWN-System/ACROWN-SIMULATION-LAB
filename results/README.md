Each substantive result should identify the model and code commit, input/data versions, configuration, exact command, runtime, seed policy, run timestamp, raw outputs, analysis procedure, acceptance criteria, failures and limitations. Include enough information to reproduce or independently audit the reported conclusion.

Label synthetic, simulated, estimated and observed data distinctly. Preserve material failed and inconclusive runs; never present a selected successful run as the complete evidence when other runs materially change the conclusion.
