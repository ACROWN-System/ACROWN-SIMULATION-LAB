# Governance Models

**Status:** reserved scaffold; no governance-model implementation was present in the reviewed baseline.

Specify actors, authority, incentives, decision rules, information access, conflict handling, failure modes and excluded conditions. Distinguish rules encoded in the simulation from how real people or institutions are evidenced to behave.

A simulated policy being followed inside the model does not demonstrate that real governance will enforce it. Record counterexamples, contested assumptions, validation evidence and the limited scope of any conclusion.

See the root [simulation evidence rules](../README.md).
