# Scenarios

**Status:** reserved scaffold; no scenario definitions were present in the reviewed baseline.

For each scenario, document the question it probes, boundary conditions, input provenance, parameter choices, rationale for inclusion, omitted cases, and whether it represents an observed case, a plausible hypothesis or a stress test.

A set of scenarios is not automatically representative, exhaustive, or predictive. Include adverse and alternative explanations appropriate to the question, and state which cases remain untested.

See the root [simulation evidence rules](../README.md).
